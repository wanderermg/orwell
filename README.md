# Orwell

VPN-шлюз на NanoPi R28S с обновлением образами и откатом.

[Читать статью](https://wanderermg.github.io/orwell/) · [Исходный текст](article.md)

Статья описывает выборочную маршрутизацию через WireGuard, сетевые сервисы,
систему только для чтения и подписанные A/B-обновления через RAUC.

`index.html` — самостоятельная HTML-страница. Пять схем находятся в `images/` в форматах PNG и SVG.
Внешние скрипты для чтения не требуются.
